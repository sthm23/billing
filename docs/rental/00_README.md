## Для кого фича

Салоны свадебных платьев/костюмов: клиент заранее бронирует комплект (платье, костюм, макияж) на дату свадьбы, вносит залог, забирает вещи накануне, возвращает после праздника.

## Решения, принятые с владельцем продукта

1. **Магазин**: флаги `salesEnabled` / `rentalEnabled`. Сейчас магазин — либо продажа, либо аренда, но флаги не запрещают смешанный режим в будущем.
2. **Товар**: `canRent` + `rentPricePerDay` на варианте. Одинаковые платья одного размера — один вариант с `quantity > 1` (поштучный учёт не нужен).
3. **Цена** = цена за день × дни × кол-во. Скидку на весь комплект (3.4 млн → 3 млн) распределяет **клиент** (web/mobile) по позициям и услугам; менеджер может поправить; бэкенд валидирует как сейчас (скидка ≤ цены, снижать может только владелец/менеджер).
4. **Дни**: возврат до 12:00 — день не считается, после 12:00 — считается (14-е → 16-е до обеда = 2 дня, после обеда = 3).
5. **Бронь = заказ**, создаётся заранее. Залог деньгами = предоплата (приход в кассу в тот же день, вычитается из итога).
6. **Залог вещью/документом** (паспорт, золото) — отдельно, в кассу не идёт, возвращается после полной оплаты.
7. **Услуги** (макияж, цветы, торт) — `AdditionalService` заказа, со скидкой.
8. **Химчистка**: при возврате продавец указывает, отправляется ли вещь в химчистку и на сколько дней (по умолчанию 1). Система показывает брони, которые попадают в этот период — решение за продавцом.
9. **Отмена брони**: сумму возврата предоплаты вводит владелец или менеджер (полностью, часть или 0).
10. **Штраф** (повреждение/просрочка): при возврате — сумма + комментарий. Просрочка автоматически не начисляется — продавец вносит её как штраф.
11. **Ранний возврат**: сумму возврата денег (0 или часть) решает владелец/менеджер.
12. **Частичный возврат**: можно вернуть часть вещей; неоплаченный остаток становится долгом, аренда — в статусе «частично возвращено».
13. **Залог-вещь** (паспорт, драгоценности) возвращается после полной оплаты.
14. **Сводка продаж**: аренда попадает в неё в момент выдачи.
15. **Время**: Ташкент (`Asia/Tashkent`).
16. **Изменение брони**: можно сдвинуть даты/поменять вещи; если вещь на новые даты занята — выбрать другую.

Открытых вопросов нет.
