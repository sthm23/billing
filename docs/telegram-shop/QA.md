## 4. Границы и безопасность

- [ ] Без заголовка `Authorization: tma …` → 401; подделанный/просроченный `initData` → 401.
- [ ] `initData` одного бота на slug другого магазина → 401/404.
- [ ] Выключенная услуга / бот неактивен / магазин приостановлен → «Магазин временно недоступен» (403 `SHOP_UNAVAILABLE`).
- [ ] 6-я ожидающая заявка от одного клиента → 429 `TOO_MANY_PENDING_REQUESTS`, текст понятен.
- [ ] Серия быстрых запросов → 429 лимита, интерфейс просит подождать.
- [ ] Товар удалён/снят с продажи после добавления в корзину → 400 `ITEMS_UNAVAILABLE`, позиция убрана из корзины.
- [ ] Открытие `https://shop.sthm23.uz/<slug>` в обычном браузере → «Откройте магазин из Telegram».
- [ ] С поддомена `shop.` недоступно всё, кроме `/api/public/tg/` (например `/api/auth/login` → 404).
- [ ] Токен бота не виден в ответах API, логах и БД открытым текстом.
